# Wiki Query Procedure

When the user asks a question about RaceSims, IERL, VRH, sim racing, SEO, competitors, vendors, meetings, decisions — follow this procedure.

## Read order (mandatory)

1. `../wiki/hot.md` — recent context cache. Often answers alone.
2. `../wiki/index.md` — find relevant pages.
3. `../wiki/domains/racesims/_index.md` for RaceSims-specific questions.
4. Open 3–5 pages most directly relevant. Follow [[wiki-links]] only if genuinely needed.

Stop at ~8 pages. Narrow the question if broader.

## Answering rules

1. Cite the wiki. Every factual claim backed by a `[[wiki-page-link]]`.
2. Distinguish wiki facts from inference. Mark synthesis: "Based on [[page1]] and [[page2]]...". Mark guesses: `(speculation, not in wiki)`.
3. Prefer wiki over re-reading raw sources.
4. File valuable answers back: `../wiki/questions/<YYYY-MM-DD>-<slug>.md` with `type: question`.
5. Surface contradictions with `> [!contradiction]` — don't pick sides.

## When wiki doesn't have the answer

Say so. Then:
- Point to raw files in `./` (racesims source dirs)
- Offer to ingest a raw file
- If structural gap, suggest creating the entity page
