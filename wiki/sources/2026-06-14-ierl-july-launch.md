# IERL July 2026 Launch — Structure & Partner Deck

## Summary

Working session that finalised the structure of the **[[ierl-indian-esports-racing-league|Indian Esports Racing League]]** (IERL) for its **July 1, 2026** launch and produced the partner presentation (`ierl-july-2026.html`, 10 slides). IERL is a monthly hot-lap league across the [[racesims-company|RaceSims]] partner network, run on [[assetto-corsa|Assetto Corsa]]. Major decisions this session: lead with the **IERL brand** (not "by RaceSims") because all centres contribute to the pool; run **manually** in July (league-hosted 24/7 server + manually-updated leaderboard) until [[uday-hyderabad|Uday]]'s [[racesims-vms-build|automation software]] is ready; adopt a **[[ierl-direct-settlement|Splitwise-style peer-to-peer settlement]]**; enforce fairness with the **[[real-penalty|Real Penalty]]** tool in a controlled, centre-only environment.

## Key facts

- **Launch:** July 1, 2026. Confirmation deadline for partners: June 20, 2026.
- **Brand:** [[ierl-indian-esports-racing-league|IERL]] is the shared, community-owned brand. "by RaceSims" dropped from the deck — partners felt RaceSims-only branding implied only RaceSims gets promoted while everyone pays in. Domain `indianesportsracingleague.com` owned by RaceSims; kept in-house for now.
- **Platform:** [[assetto-corsa|Assetto Corsa]], 2 league-hosted dedicated servers (Amateur + Pro), 24/7, 60-min qualifying loops. Base game, no DLC.
- **Track (Season 1):** [[mugello|Mugello]]. Rotates from Season 2.
- **Classes:** Amateur = Mazda MX-5 ND (ABS + TC allowed); Pro = Ferrari 488 GT3 (TC disabled). Fixed/common setups. [[ierl-promotion-ladder|Promotion ladder]] moves fast amateurs up.
- **July prize pool:** ₹2,500/rig → ₹42,500 gross (17 confirmed rigs) − ₹2,500 tech = **₹40,000 net**, split 50/50 Amateur/Pro. Per class: 1st ₹12,000 / 2nd ₹5,000 / 3rd ₹3,000.
- **Local centre champion:** ₹500 × rig count, **centre-funded**, separate from the network pool (2 rigs → ₹1,000 … 8 rigs → ₹4,000).
- **Settlement:** [[ierl-direct-settlement|direct peer-to-peer]] — the league never holds money; matches each dealer's contribution to specific winners; each dealer makes 1–2 UPI transfers.
- **Anti-cheat:** [[real-penalty|Real Penalty]] tool enforces strict track limits + auto penalties; identical centre hardware + enforced software = controlled environment, no scope for cheating. **This is why IERL runs in-centre, never from customers' homes.**
- **Manual interim:** until [[racesims-vms-build|the VMS / automation]] is ready, lap times are submitted manually to the leaderboard. Automated kiosk + auto-logging is "coming soon."

## Network & timeline

- **July (6 confirmed, 17 rigs, ₹42,500):** [[sim-racing-adda]] (Delhi, 4) · [[niyusuki-sim-racers]] (Cochin, 3) · [[lights-out-racing]] (Delhi, 3) · [[drivextreme]] (Coimbatore, 3) · [[bbs-adrenaline-apex]] (Mangalore, 2) · [[virtual-adda]] (Mumbai, 2).
- **TBC:** [[racing-point-esports]] (Hyderabad, 8) — [[uday-hyderabad|Uday]]'s centre, joins once his [[racesims-vms-build|software]] is ready.
- **August 2:** [[racesims-chennai-flagship|RaceSims Studio]] (Chennai, 8) joins → full 8-centre network, 33 rigs, ₹82,500/month, ₹80,000 pool.

## People mentioned

- [[thambu]] — owner/operator, running the league.
- [[uday-hyderabad|Uday]] — Hyderabad partner ([[racing-point-esports]]); building the [[racesims-vms-build|VMS automation]] the league waits on.

## Decisions

1. Brand the league as IERL, not "by RaceSims". RaceSims Studio Chennai participates as one centre among equals.
2. Run July manually; automation ships with [[racesims-vms-build|Uday's VMS]].
3. [[ierl-direct-settlement|Splitwise-style settlement]] — no central pot.
4. [[real-penalty|Real Penalty]] + centre-only controlled environment.
5. [[mugello|Mugello]] / MX-5 ND + Ferrari 488 GT3 for Season 1.
6. Local prize = ₹500 × rigs, centre-funded.
