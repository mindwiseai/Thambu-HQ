# Conspit Import Justification — HS Code 9023.00.90

Legal justification letter for customs classification of [[conspit|Conspit]] simulation hardware (direct drive wheelbases, steering wheels, pedal sets) under HS Code 9023.00.90 as demonstrational apparatus for motorsport training, not recreational gaming. Signed by [[thambu|Thambusamy T.D.]], Founder – RACE.SIMS.

## Summary

Letter affirms that [[conspit|Conspit]] imports are for professional motorsport training infrastructure, not casual gaming. Requests classification under HS Code 9023.00.90 ("Instruments, apparatus and models, designed for demonstrational purposes, not for medical, surgical, dental or veterinary use: Other") to avoid gaming/recreational equipment tariff classification. Establishes end-use exemption justification for duty/tax purposes.

## Key facts

- **HS Code requested**: 9023.00.90 — demonstrational apparatus category (not gaming equipment)
- **Equipment scope**: direct drive wheelbases, steering wheels, pedal sets
- **End-use statement**: "professional-grade simulators to replicate real-world racing conditions for the training and development of motorsport enthusiasts and professional drivers"
- **Exclusion claim**: "not intended for casual or recreational gaming use"
- **Company name on letter**: RACE.SIMS (note: also styled as RaceSims or racesims.in)
- **Signer**: Thambusamy T.D., Founder – RACE.SIMS
- **Regulatory framework**: targets duty/tax advantage via end-use justification

## Status

Standard import justification document filed with customs. Likely used for multiple [[conspit|Conspit]] shipments under the same HS classification basis.
